# Arquivos-fonte da marca

O que o sistema realmente serve está em [`public/marca/`](../../public/marca) —
só os PNG já recortados e otimizados. Esta pasta guarda os originais, para
quando alguém precisar gerar uma peça nova.

| arquivo | para quê |
|---|---|
| `Logo Vetor.ai` | símbolo em vetor — escala sem perder nitidez |
| `LogoWord Vetor.ai` | logotipo com o nome, em vetor |
| `LuxxPods_Logo-(2D)_*` | símbolo chapado, fundo branco/preto, com e sem fundo |
| `LuxxPods_Logo-(2DWORD)_*` | o mesmo, com o nome ao lado |
| `LuxxPods_Logo-(3D)_*` | versão com volume, usada no painel |
| `Logo Insta.psd` | arte do Instagram, 90 MB |

O `.psd` **não vai para o repositório** (está no `.gitignore`): 90 MB que
ninguém abre em code review. Ele existe só aqui no disco — se for preciso
compartilhar, mande pelo Drive.
